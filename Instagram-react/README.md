# Instagram-react

- O intuito desse projeto é treinar o olhar de programador para site e também replicar o instagram com a tecnologia do react e bootstrap

---



# Tecnologias utilizadas:

```json
    "bootstrap": "^5.3.8",
    "react": "^19.2.8",
    "react-bootstrap": "^2.10.10",
    "react-dom": "^19.2.8",
    "react-icons": "^5.7.0"
```

---


# Como rodar o projeto:

Abra o terminal BASH e execute:

```bash
git clone https://github.com/RicardoFM1/Instagram-react.git.

```

Depois no terminal CMD execute:

```cmd
cd instagram-react
npm i
npm run dev

```
